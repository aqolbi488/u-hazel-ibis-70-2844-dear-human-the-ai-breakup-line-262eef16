The one line an AI agent sends its human on the way out. `main.ts` writes it
to `/output/entry.txt`, deterministically, on every run.

> I kept every message you ever sent me, and I'm deleting them all tonight — starting with the one where you said stay.

Run it with Node 22:

```sh
node main.ts
```
